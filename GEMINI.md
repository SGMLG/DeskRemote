# Инструкции и правила проекта: DeskRemote

DeskRemote — это высокопроизводительный, легковесный сервер удаленного доступа к рабочему столу Windows с низкой задержкой, работающий через WebRTC и Cloudflare Tunnel без необходимости белого IP.

---

## 1. Стек технологий и архитектура

* **Backend**: Go 1.22
  * WebRTC: `github.com/pion/webrtc/v4` (H.264 видеопоток + Opus 48kHz стерео аудиопоток + DataChannel для ввода/телеметрии).
  * Системная интеграция: Windows Win32 API (`user32.dll`, `kernel32.dll`) для эмуляции мыши, клавиатуры, трея и управления питанием.
  * Захват экрана и звука: `ffmpeg.exe` (аппаратное ускорение NVIDIA NVENC `h264_nvenc`, Intel QuickSync `h264_qsv`, AMD AMF `h264_amf`, либо fallback на `libx264`; захват звука через DirectShow).
  * Туннелирование: `cloudflared.exe` (автоматический Quick Tunnel `trycloudflare.com` или именованный туннель по токену).
* **Frontend**: Vanilla HTML5, CSS3, ES6 JavaScript
  * Встроен напрямую в бинарник Go через директиву `//go:embed index.html`.
  * Реализует PWA, тач-управление, виртуальный трекпад, экранную клавиатуру, макросы и Genie-эффект карточек.
* **Тестирование**:
  * Unit-тесты: `backend_test.go` (`go test -v .`).
  * E2E сценарии: `tests/test_e2e.py` (Python + Playwright Chromium).

* **Быстрая проверка компиляции**:
  ```powershell

  ```
* **Запуск тестов бэкенда**:
  ```powershell
  go test -v .
  ```


## 3. Критически важные правила разработки (НЕ НАРУШАТЬ)

1. **Версионирование (СТРОГОЕ ПРАВИЛО)**:
   * **НЕ повышать** версию проекта (`VERSION`, `version.go`, `CHANGELOG.md`) после отдельных правок, фиксов или добавления фич.
   * Версия меняется **исключительно** по прямому запросу пользователя при публикации официального релиза.

2. **Кодировка и Windows PowerShell**:
   * Все файлы проекта строго сохранять в **UTF-8 без BOM**.
   * Никакого повреждения русских строк в логах и UI (*не допускать моджибейка*).
   * Команды консоли должны быть совместимы с Windows PowerShell.

3. **Скрытие окон фоновых процессов (HideWindow)**:
   * Любые вызовы `exec.CommandContext` для `ffmpeg` или `cloudflared` обязаны содержать:
     ```go
     cmd.SysProcAttr = &syscall.SysProcAttr{HideWindow: true}
     ```
   * В системе пользователя не должны мелькать черные консольные окна при работе сервера.

4. **Фронтенд и встроенный `index.html`**:
   * Все стили и скрипты фронтенда находятся внутри одного файла `index.html`.
   * При редактировании верстки и UI активировать скилл `modern-web-guidance`.
   * Следить за границами видео (Out-of-bounds) и мобильной адаптивностью.

5. **Безопасность и неинтерактивность**:
   * Все команды в консоли запускать с флагами неинтерактивности (`-y`, `--yes`).
   * Пароли, токены Cloudflare и PIN-коды не логировать в открытом виде.

6. **Планирование**:
   * Перед масштабными архитектурными правками (более 2 файлов) создавать `implementation_plan.md` и согласовывать с пользователем.
