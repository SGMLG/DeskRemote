**DeskRemote** — ультралёгкая программа для удаленного управления домашним компьютером прямо через любой веб-браузер (на ПК, планшете или смартфоне) без необходимости статического IP, проброса портов (NAT) и установки сторонних клиентов на управляющее устройство.

Идеально подходит для подключения с компьютеров в университетах, библиотеках или офисах с закрытыми портами и ограниченными правами доступа.

---

## ✨ Основные возможности

- ⚡ **WebRTC Стриминг (60 FPS)**: передача видеопотока с минимальной задержкой через VP8 (libvpx) аппаратный захват экрана.
- 🌐 **Работа через Cloudflare Tunnel**: автоматическое создание защищенного HTTPS/WSS туннеля. Работает через стандартный порт `443`, обходя любые строгие брандмауэры и прокси.
- 📱 **Мобильный режим и тач-управление**: адаптивный веб-интерфейс с поддержкой тапов, перетаскиваний и автоматическим разворачиванием на весь экран при входе.
- 🔒 **PIN-авторизация**: защита подключения персональным PIN-кодом.
- 🗔 **Фоновая работа в системном трее**:
  - Копирование ссылки для подключения в 1 клик.
  - Быстрый запуск в браузере.
  - Переключатель автозапуска с Windows.

## 🚀 Быстрый старт (для пользователей)

1. Перейдите во вкладку [**Releases**](../../releases) и скачайте свежий архив `DeskRemote-vX.Y.Z-Windows-x64.zip`.
2. Распакуйте архив в удобное место (например, `C:\DeskRemote`).
3. Запустите **`DeskRemote.exe`**.
4. В системном трее (возле часов) появится иконка. Через 5–7 секунд ссылка на подключение автоматически скопируется в ваш буфер обмена.
5. Откройте эту ссылку на телефоне или удаленном ПК, введите PIN (`1234` по умолчанию) и управляйте рабочим столом!

## 🛠️ Сборка из исходников

### Требования:
- [Go 1.22+](https://go.dev/dl/)
- Внешние бинарники `cloudflared.exe` и `ffmpeg.exe` (скачиваются автоматически скриптом сборки).

### Автоматическая сборка (1 клик):
Запустите в PowerShell:
```powershell
.\build.ps1
```

### Ручная сборка:
```powershell
# 1. Загрузить зависимости
go mod tidy

# 2. Скомпилировать GUI бинарник
go build -ldflags "-H=windowsgui -s -w" -o DeskRemote.exe .
```

## 🔒 Безопасность

- Все веб-соединения и передача сигналов защищены сквозным шифрованием TLS/HTTPS через Cloudflare.
- Видеопоток и события ввода шифруются по протоколу DTLS/SRTP (WebRTC).
- Для изменения стандартного PIN-кода запустите с флагом:
  ```powershell
  .\DeskRemote.exe -pin 9876
  ```
